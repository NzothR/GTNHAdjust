# T10 新矿石处理粉末的材料形态

依据 GTNH 2.9.0 客户端的 `singularity-registries.json` 矿辞和流体注册表快照，结合 GT 材料定义，核对 [T10 新矿石处理产物](t10-ore-processing.md) 中去重后的粉末。结果作为固定清单保存在 [t10_material_forms.json](../src/main/resources/assets/gtnhadjust/recipes/t10_material_forms.json)，不读取运行时配方。

按需求，磷、橄榄石、力之宝石、力场宝石、铂金属、氟石和稀土系列未纳入此次形态核对。其余 37 种材料中，34 种在快照中有普通锭，36 种有对应熔融流体。未查到的形态如下：

| 粉末材料 | 普通锭 | 熔融流体 |
|---|---|---|
| 磷酸盐 | 未查到 | 未查到 |
| 奶酪 | 未查到 | 有：熔融奶酪 |
| 合成玉 | 未查到 | 有：熔融合成玉 |

存在的锭和流体会分别并入 T10 的 23 号和 24 号电路配方，再与原有产物去重。客户端和服务端需要相同版本及配置并重启；最终显示与机器运行由游戏内验证。

## 多来源核对

| 材料 | 当前选用 | 核对依据 |
|---|---|---|
| 玛玉灵 | GregTech 锭及粉 | 用户提供的线材轧机配方显示 GregTech 锭；实例矿辞中也有 GregTech 粉。 |
| 妖金 | Witchery 锭及粉 | 实例矿辞中普通锭只有 Witchery 版本，同来源粉已注册。 |
| 终末 | 末影扩展锭、GregTech 粉 | GT 源码明确指定末影扩展锭；实例矿辞中粉只有 GregTech 版本。 |
| 暗影金属、灵宝 | GregTech 锭及粉 | 当前选用的 GregTech 锭及粉均已注册；灵宝的锭统一目标在 GT 源码中明确指定。 |
| 银 | 原有锭及粉 | 实例有多个锭来源，现有注册表快照未包含线材轧机的实际输入，需在游戏内进一步核对。 |
| 铁、金 | 原有锭及粉 | 原版锭已有明确的 GT 统一目标，实例没有同模组的粉；这些材料也存在于 T0–T9。 |

实例中的矿辞快照不包含线材轧机配方，除用户提供的玛玉灵截图外，上表没有将材料来源表述为已逐条核对游戏内轧机配方。
