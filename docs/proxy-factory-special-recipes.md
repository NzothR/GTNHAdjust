# 代理联合工厂特殊配方初查

本表是针对已开放候选配方池的源码初查，并非所有第三方配方的完整逐条审计。不同整合包及模组版本会改变配方，运行结果需要游戏内验证。

| 配方池 | 原机器或配方特殊点 | 代理联合工厂目前的行为 |
| --- | --- | --- |
| 秘法炼金 `gtnl.recipe.alchemic_chemistry_set` | LP 记录为 specialValue，注册 EU/t 为 0。 | 不扣 LP，使用通用超频和持续时间。 |
| 血魔注入 `gtnl.recipe.blood_demon_injection` | 血祭坛需求记录为 specialValue，注册 EU/t 为 0。 | 通用逻辑不读取该 LP 值；继续保留既有行为，待用户决定。 |
| GTNL 魔力灌注与符文祭坛 | 转换配方把魔力写为流体输入，部分催化剂写为零数量物品。 | 仍按 GT 流体和催化剂规则匹配，不会自动免除魔力。 |
| 核聚变 `gt.recipe.fusionreactor` | 原聚变堆验证配方启动能量阈值。 | 使用代理工厂的常规功率检查，不执行原堆启动能量阈值检查。 |
| 热解炉 `gt.recipe.pyro` | 原机器速度随线圈等级变化。 | 不使用原热解炉线圈速度，仍使用代理工厂玻璃和通用超频。 |
| TST 炼金塔、注魔矩阵 | 源质要求存于特殊槽展示物品及配方元数据。 | 要求主机槽有创造源质元件；不执行原机器源质网络消耗。 |
| GTNL 坩埚、注魔、奥术装配 | 配方元数据记录源质或魔力与研究；NEI 展示源质。 | 要求主机槽有创造源质元件，不执行原机器的源质和研究检查。 |
| 梦魇转换 `tst.common.recipe.VisualExtremeCraftRecipeMap.name` | 从终极工作台配方转换为 GT 配方，转换器有自己的跳过列表；配方 EU/t 为 0。 | 只读取转换后的池，按代理工厂的通用匹配、并行及超频执行。 |

参考：`ref/gtnl-snapshot` 中配方构建代码，`ref/Twist-Space-Technology` 的配方转换和机器代码，`ref/GT5-Unofficial` 的聚变堆及热解炉实现。仓库中的参考源码可能与实际服务端版本存在差异。
