# GTNR 非机器功能对照

对照 GT-Never-Reset 0.1.47 发行源码及主分支 `b2d00e4`，GTNH 基线为 2.9.0。此表记录静态代码与上游提交的对照，实际交互需在游戏内验证。机器与其专属调整不在本表范围。

| 本模组功能 | GTNR 对照 |
| --- | --- |
| 二合一终端快捷编码、自动上传、收藏编码、智能选材、样板去重和接口偏好 | GTNR 提供终端和基础 NEI 导入；本模组提供上述扩展，保留。上游已修复接口列表容量变化后的搜索缓存，和本模组保存界面偏好作用不同。 |
| 配方池保留 | 0.1.46 起 GTNR 保留切换 NEI 候选材料时的配方池；本模组还处理手动编辑已有样板后的重新编码，范围不同，保留。 |
| 终端库存同步与 NEI 材料状态 | GTNR 在终端配方格显示可合成标记；本模组在终端被 NEI 配方界面覆盖时转发库存更新，并展示 NEI 状态及材料提示，位置和用途不同。 |
| GTNL NEI 请求合成终端槽位修复 | 修正 GTNL 请求从 GTNR 二合一终端打开时的槽位；未在本次 GTNR 更新中发现相同修复。 |
| 装配矩阵样板加载修复、终端合成状态刷新、GTSR 配方速度兼容及诊断 | 未在本次上游相关改动中发现可直接替代的同范围修复；保留既有开关。诊断不改变配方行为。 |
| 全息投影替换与 AE 取料、任务 AE 检索、灵魂瓶捕获扩展、GTNL 大型装配线自动维护、蒸汽温室调整、木工机配方、NEI 页面隐藏 | 面向 StructureLib、BetterQuesting、Ender IO、GTNL、Forestry 或 NEI 的调整；本次上游变更中未发现同范围功能。 |
| YSMU 第一人称手臂兼容 | GTNRLib 提供自身第一人称动画并新增副手及工具箱动画；本模组让动画使用 YSMU 模型手臂，作用不同。 |

GTNR 0.1.47 发布后的主分支修复了切换 NEI 候选材料时的客户端预测顺序；该修复尚不包含在 0.1.47 正式包内。测试候选切换时应留意这一版本差异。
