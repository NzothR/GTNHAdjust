# GTNH Adjust

面向 **GT New Horizons 2.9.0** 的调整模组。通过 Mixin 改善终端、NEI、结构建造和既有机器，并添加代理加工、资源解压和战利品模拟等多方块机器。

## 环境与安装

| 组件 | 当前适配版本／用途 |
| --- | --- |
| Minecraft / Forge | GTNH 2.9.0 使用的 1.7.10 环境 |
| GregTech | 5.09.54.265，包含 GT++ 与 TecTech |
| GT-Never-Reset / GTNRLib | **0.1.48 / 0.1.35**，机器、终端和样板功能 |
| GT-Not-Leisure / GTNLLib | GTNH 实例的 **dev-290 / 1.1.5**，机器制作、温室及兼容功能 |
| AE2 / NEI / ModularUI2 / StructureLib | 使用 GTNH 2.9.0 及上述扩展模组对应版本 |
| 按功能使用的模组 | BetterQuesting、Forestry、Ender IO、KubaTech、MobsInfo、RemoteIO、NotEnoughEnergistics、NECH、GTSteamReborn、YSMU、TST 等 |

将构建产物 `gtnhadjust-*.jar` 放入客户端与服务端的 `mods`，安装对应扩展模组及其依赖，再启动游戏。二合一终端适配 GTNR 0.1.48，不支持旧版终端实现；这不是一个独立于 GTNH 的通用模组。

客户端与服务端应使用相同模组版本、玩法开关及机器 ID。NEI 隐藏、书签整理和第一人称动画等纯客户端功能按客户端配置生效。更新或修改启动配置后重启。

## 新增机器与工具

| 内容 | 安装后可以做什么 |
| --- | --- |
| **代理联合工厂** | 用多个定位器共享已成型多方块的配方池，同时执行不同类型配方。线程和并行随电压增长，玻璃提升效率，产物送入 AE。UEV+ 玻璃且无能源仓时使用无线电网。 |
| **多线程联合代理** | 内置默认 1024 格样板栏，按槽位顺序启动独立线程；中键设置耗能、并行、OC 与一次性产量估算。从普通输入舱室取料、向输出舱室交付产物，支持批处理、蓄水仓免水和无线供电；主机可联网查询 PH 工具。 |
| **物质解压器** | 使用维度标记与电路获取矿石、宝石、粉末、锭及流体，支持 T0–T10 资源配方、多线程和无线供电。采用黑洞遏制场布局及独立黑洞、约束场和向外喷流特效。 |
| **战利品模拟室** | 放入有生物灵魂瓶、刷怪笼或刷怪蛋，定期生成模拟掉落和液态经验；输入不消耗、不生成实体、不耗电，线圈提高产出。 |
| **配方池调试主机** | 在物品上按 U 浏览所有已注册 GT 配方池及目录，无需搭建或运行。 |
| **多方块主机定位器** | 潜行右键主机记录位置并供代理机器使用；对空气右键高亮，潜行对空气右键安全传送并高亮，支持跨维度。 |

两种代理都要求定位来源在新线程启动时已加载、身份正确且结构成型。高炉配方检查实际炉温，支持诸神锻炉高炉模块的有效加工炉温；代理工厂另支持 TST 梦魇工作台转换加工样板。

两种代理缺电跳停时立即清空全部已启动线程，包括已完成但等待输出的缓存产物，已消耗输入不退回。未投入线程的输入和样板保留；手动暂停及结构停机保留线程。此前已按缺电跳停保存的残留线程在读档时丢弃。行为随 `proxyFactory`／`threadedJointProxy` 启停，适配 GTNH 2.9.0，更新后两端重启。

常用操作：制作定位器并记录主机，在代理 GUI 的输入模式放入定位器，再切到运行模式。多线程联合代理在“样板栏”放入带配方池信息的加工样板，在普通输入舱室提供原料；样板总成可选，其共享槽仍能提供催化剂。两种代理的“主机栏”用于定位器；搜索隐藏不匹配槽位并紧凑排列。

结构、供料、无线账户、输出和停机规则见 [机器使用说明](docs/machines.md)。主机制作与结构材料可在游戏内查看 NEI 和全息投影仪。

## 配方调整与模组兼容

PH 编程工具包的三个正常模式加入虚拟工具目录。代理联合工厂等使用 GTNR 样板的机器在配方要求零数量工具包时免提供，修复编程器电路提供器 (T1) 配方已收到普通原料仍不能启动的问题；配方实际消耗的工具包继续作为普通原料。沿用 `gtnrVirtualTools` 开关，适配 GTNH 2.9.0、GTNR 0.1.48／0.1.50 和 PH 0.2.1p7，更新后两端重启。已保存完整 NC 的样板可以继续使用。

GTNR 样板编码会跳过编码区的空槽，修复手动点击编码按钮时的服务端异常断连。恒星冶炼配方的白矮星锭模具仅作特殊槽提示，编码时从普通原料及 NC／模具元数据中省略；已编码为普通输入的样板需重新编码。两项修复随 `gtnrVirtualTools` 生效，适配 GTNH 2.9.0、GTNR 0.1.48／0.1.50 与 TST 0.8.1，更新后两端重启。

- **Forestry 木工机配方**：添加到 GT 组装机的静态配方，包含农场方块相关配方。
- **维度与资源配方**：物质解压器增加维度／等级资源池、等级标记制作、黑洞压缩机压缩标记，以及 T10 太空采矿、钻井和材料形态资源。
- **GTSteamReborn**：保留其注册配方的原始耗时，避免与 GTNR 全局配方加速引发自检冲突。
- **GTNL × GTNR**：修复从 NEI 请求 AE 合成时选错无线终端槽位的问题。
- **装配矩阵**：通过样板副本解码和延迟重验处理读档后误判失效的合成样板。
- **YSMU × GTNRLib**：第一人称持物动画使用 YSMU 当前模型手臂。
- **NeoECOAE**：提供可选合成状态刷新修复，默认关闭。

## 配方调整

将静态清单中的 Forestry 木工机及农场方块配方加入 GT 组装机，便于现有组装机产线制作，保留原配方。由 `carpenterRecipes` 开关控制。

物质解压器提供单维度与 T0–T10 等级资源配方，并增加等级维度标记的组装机配方；9 个同种维度方块还可在具有活跃黑洞的黑洞压缩机中制成对应等级标记。由 `collector.singularityResourceRecipes` 控制。

## 配置

样板栏与主机栏的动态槽位先完成原生网格尺寸计算，再排列搜索结果；切换页面时刷新布局，修复搜索框下方槽位区域空白的问题。修复沿用两种代理原有功能开关，适配 ModularUI2 2.3.94，更新后客户端与服务端重启。

`config/gtnhadjust-features.properties` 控制各项 Mixin、代理机器和独立功能。关闭 Mixin 功能时，不把对应 Mixin 加入加载列表。`config/gtnhadjust.cfg` 设置机器 ID、容量、无线供电、资源配方与特效等参数。

多数玩法功能默认开启。常用开关包括 `gtnrVirtualTools`、`proxyFactory`、`threadedJointProxy`、`lootSimulator`、`quickTerminal`、`bookmarkMachineGroups`、`hologramImprovements`、`questAeRetrieval`、`carpenterRecipes`。多线程代理无线开关为 `threadedJointProxy.wirelessPower`，默认开启；日志总开关 `general.debug` 默认关闭。

多线程代理内部容量为 `threadedJointProxy.patternSlots`（默认 1024），样板及独立参数随挖下的主机保存。新界面、顺序调度和主机 AE 接入随原 `threadedJointProxy` 开关生效，适配 GTNH 2.9.0、GTNR 0.1.48／0.1.50、AE2 rv3-beta-1095 和 ModularUI2 2.3.94；两端同步更新并重启。

完整开关与默认值见 [配置说明](docs/configuration.md)。
